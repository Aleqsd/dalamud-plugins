Hi! I'd like your advice before submitting Minimap Zoom.

It extends the native minimap zoom to 0.25–2 (native minimum: 0.5), offers a square shape and custom frames, and lets users resize or hide existing marker categories. It also increases the native marker collection range as the map zooms out, without a safe-category allowlist. It keeps the native 100-marker limit and uses data already available to the client, but the wider view could still matter in combat or PvP. There is currently no PvP disable. It doesn't change the world camera.

Would this scope be acceptable for the testing repository? Would you want a native zoom limit or a PvP restriction? I'd rather agree on that before submitting.
