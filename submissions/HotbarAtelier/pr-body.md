Hi! I'd like to share **Hotbar Atelier**, a plugin for giving the ten keyboard hotbars a more personal look: icon shapes, borders, colours, size and layout.

It changes the existing hotbar UI and includes a restore option. It starts disabled and doesn't choose or execute actions. The cross hotbar isn't supported. `/hotbaratelier` opens the settings.

**AI usage: Auto (OpenAI Codex).** Codex wrote most of the code and ran autonomous implementation and testing passes. I chose the features, tested the plugin in game and guided improvements with my own ideas and feedback. Codex also helped prepare this submission.

The installer icon, procedural skin textures and preview artwork were created with Codex. This is disclosed in the plugin description. The previews show the real ImGui interface and generated skin samples outside the game. If the AI-made icon is an issue, I'm happy to make one by hand 🙂

This is an initial testing submission. Local build checks and in-game testing are recorded separately in the preparation notes. Thanks for taking a look — I'm happy to discuss changes!
